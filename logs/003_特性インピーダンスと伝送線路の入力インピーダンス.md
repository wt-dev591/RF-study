# 003 特性インピーダンスと伝送線路の入力インピーダンス

## 目的
負荷インピーダンスが伝送線路を通してどのように見えるかを理解する。

## 理論
- 特性インピーダンス Z0
- 伝送線路長 l
- 入力インピーダンス Zin
- λ/4 線路でインピーダンスが反転する理由

## 手計算
- Z0 = 50Ω
- ZL = 25Ω / 100Ω / open / short
- l = λ/4 のときの Zin を計算

## Qucs-Sでの確認
- 伝送線路 + 負荷を置く
- 周波数を掃引
- S11 と Zin を確認

## 気づき
- λ/4 で open/short が反転する
- 整合回路やスタブフィルタの基礎になる
